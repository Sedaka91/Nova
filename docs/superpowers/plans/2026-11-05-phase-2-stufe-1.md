# Phase 2: Stufe 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nova führt feste Befehle ohne Modell aus: Musik, Wetter, Programme öffnen, Google- und YouTube-Suche. Das Echo aus Phase 1 entfällt.

**Architecture:** `parse` ist rein und läuft in `step`; ein erkannter Befehl führt in den Zustand `Working`. Der Treiber startet pro Befehl einen Arbeits-Thread, dessen `Reply` über den vorhandenen `mpsc`-Kanal zurückkommt. Jedes Modul trennt reine Auswertung (getestet) vom dünnen Aufruf (in der Abnahme geprüft).

**Tech Stack:** Rust 2024, Threads mit `std::sync::mpsc`, ureq 3 (synchron), percent-encoding, sha2, base64; Kindprozesse `playerctl`, `gtk-launch`, `xdg-open`, `secret-tool`; Open-Meteo; Spotify Web API (Development Mode).

**Spec:** `docs/superpowers/specs/2026-11-05-phase-2-stufe-1-design.md`

## Global Constraints

- Bezeichner und Code-Kommentare englisch; Konfiguration und alles, was Nova sagt, deutsch.
- Vor jedem Commit: `cargo fmt --all && cargo clippy --all-targets && cargo test`.
- `unsafe_code = "forbid"` bleibt. Kein `sudo`, keine Shell: Kindprozesse nur mit einzeln übergebenen Argumenten.
- Jede neue Option wird in `nova-core` typisiert und validiert (`deny_unknown_fields`).
- Fristen: HTTP-Timeout 5 s, Arbeitsfrist 20 s, Login-Wartezeit 120 s. Redirect-URI `http://127.0.0.1:8898/callback`.
- Gesprochene Sätze wörtlich aus der Spec, auch die Fehlersätze.
- Tests fassen weder Netzwerk noch `playerctl`, `gtk-launch`, `xdg-open` oder KWallet an.
- Tokens und Client-ID nie im Log, nie in `config/*.toml`, Werte an `secret-tool` nur über stdin.
- Commits klein und thematisch auf Branch `phase-2-stufe-1`, Nachrichten deutsch, mit Zeile `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Nur die Dateien des jeweiligen Tasks einzeln mit `git add` aufnehmen: `.gitignore` und `training/` gehören zum parallel laufenden Wake-Word-Training und bleiben unberührt.

## Review Focus

1. Whisper schreibt Zahlen auch als Wort („Lautstärke auf dreißig“): Volle Zehner und „hundert“ wirken wie Ziffern (Task 2).
2. Whisper schreibt „VS-Code“ mit Bindestrich: Das Programm wird trotzdem gefunden, ein Teilwort aber nicht (Task 4).
3. Temperatur rundet auf null von unten (`-0.4`): Gesprochen wird „0 Grad“, nicht „minus 0 Grad“ (Task 6).
4. Open-Meteo liefert `precipitation_probability_max: null`: Der Regenteil des Satzes entfällt, kein Absturz und kein „null Prozent“ (Task 6).
5. Der Nutzer entzieht der App den Zugriff: `invalid_grant` beim Erneuern führt zu „Spotify ist noch nicht angemeldet.“, nicht zu „nicht erreichbar“ (Task 7).
